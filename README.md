📖 Sobre o Projeto

Este projeto tem como objetivo o desenvolvimento de um sistema de gestão de estágios, focado em centralizar, organizar e otimizar todo o processo de candidatura e acompanhamento de vagas.

A plataforma conecta alunos, empresas e instituição de ensino, promovendo uma comunicação mais eficiente e estruturada entre as partes envolvidas.

🎯 Funcionalidades
👨‍🎓 Para Alunos
Visualização de vagas de estágio
Candidatura em oportunidades
Acompanhamento do status do processo seletivo
🏢 Para Empresas
Cadastro e gerenciamento de vagas
Análise de candidatos
Processo de seleção
🏫 Para a Instituição
Validação de estágios
Monitoramento das atividades
Garantia de conformidade com normas acadêmicas
💡 Objetivo

O sistema busca resolver problemas comuns no processo de estágio, como:

Falta de organização das candidaturas
Comunicação ineficiente entre alunos e empresas
Dificuldade no acompanhamento institucional

👉 A solução propõe uma plataforma única e centralizada, aumentando a transparência e eficiência do processo.
