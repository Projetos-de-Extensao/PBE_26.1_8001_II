# 5W2H

## Introdução

O 5W2H é uma ferramenta administrativa utilizada para planejamento e organização de ações. Baseia-se em 7 perguntas (What?, Why?, Where?, Who?, When?, How? e How much?), com o intuito de esclarecer e organizar ideias. A ferramenta foi utilizada como guia de ações, tornando os objetivos mais evidentes para a equipe e auxiliando na compreensão, organização e tomada de decisões no projeto.

## Metodologia

A equipe se reuniu via Discord para esclarecimento sobre o tema do projeto. A partir dos pontos debatidos, foi possível responder às questões do 5W2H em duas versões: uma visão geral do problema e uma visão voltada ao produto.

## Questões 5W2H

### Versão 1.0

### Visão geral

| Pergunta | Resposta |
|---|---|
| **What?** (O que será feito?) | **Gerência de Estágios Acadêmicos do Ibmec** |
| **Why?** (Por que isso será feito?) | Para garantir o controle, a organização e a conformidade dos estágios dos alunos com as normas institucionais e educacionais. |
| **Where?** (Onde será feito?) | No ambiente institucional do Ibmec, por meio de uma plataforma digital acessível aos envolvidos. |
| **When?** (Quando será feito?) | De forma contínua durante os períodos letivos, acompanhando todo o ciclo dos estágios. |
| **Who?** (Quem irá fazer?) | Coordenação de curso, professores orientadores e setor administrativo responsável pelos estágios. |
| **How?** (Como será feito?) | Por meio de um sistema de gestão de estágios que permita cadastro, acompanhamento e validação das atividades dos alunos. |
| **How much?** (Quanto custará?) | Custos operacionais relacionados à manutenção do sistema e à gestão administrativa. |

### Versão 2.0

### Visão produto

| Pergunta | Resposta |
|---|---|
| **What?** (O que será feito?) | **Sistema de Gestão de Estágios Acadêmicos** |
| **Why?** (Por que isso será feito?) | Para automatizar o controle de estágios, incluindo cadastro, acompanhamento e validação das atividades dos alunos. |
| **Where?** (Onde será feito?) | Em um sistema web acessado por navegadores, disponível para alunos, empresas e coordenadores. |
| **When?** (Quando será feito?) | Durante o semestre 2026.1, com funcionalidades entregues gradualmente. |
| **Who?** (Quem irá fazer?) | Rafael Barbosa, Gabriel Lima, Jorge Alves, Davi Ito e Gabriel Aguiar. |
| **How?** (Como será feito?) | Através do desenvolvimento de um sistema com funcionalidades como cadastro de estágio, envio de documentos, validação e relatórios. |
| **How much?** (Quanto custará?) | Custo relacionado ao tempo de desenvolvimento, sem necessidade de investimento financeiro elevado. |

## Conclusão

O 5W2H é uma técnica simples e de fácil entendimento, sem necessidade de um especialista. Dentro da disciplina, a técnica forneceu um entendimento melhor para a equipe sobre o projeto, definindo responsabilidades, motivação e organização das ações a serem executadas.
